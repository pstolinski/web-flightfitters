# FlightFitters static site

This is a GitHub Pages-ready static rebuild of the public FlightFitters site.

## Deploy

1. Create a public GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In GitHub, go to Settings -> Pages.
4. Set the source to Deploy from a branch and choose main / root.
5. Add the custom domain `flightfitters.com` in Pages settings if needed.
6. Point your DNS at GitHub Pages.

## Notes

- This version intentionally removes WordPress and uses direct contact links instead of a database-backed form.
- If you want a hosted form later, connect a static form service.
